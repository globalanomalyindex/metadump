# metadump-skill

A Claude Code plugin/skill that turns a prompt into a **meta dump**: one large structured JSON file of retrieval metadata (tiered keywords, anti-keywords, descriptions, palettes, patterns, inspiration, measurements, timings, transcripts) that the model then queries like a search index throughout the build. It is a resource to consult, not a source of truth to obey (`docs/adr/0003-reference-resource-not-source-of-truth.md`).

## Testing (TDD)

Follow Matt Pocock's `tdd` skill (one red-green slice at a time) with these project rules:

1. **Pre-agreed seams only.** Tests live at the public seams listed in `docs/agents/tdd-seams.md`, never against internals. Need a seam that is not there? Propose it (what it catches, what it misses) and get it agreed before writing the test.
2. **Vertical slices.** One failing test, watched failing for the right reason, then the minimal code to pass it, then the next. No batches of tests written ahead of the code.
3. **No tautological tests.** Expected values come from an independent source: hand-written literals, a fixture's known schedule, the spec. Never recomputed the way the code computes them, and never generated by the module under test.
4. **Mock only at system boundaries** (network, browser transport, time, sometimes the filesystem) through injected SDK-style interfaces (`Fetcher(raw_fetch=..., clock=...)`, `tools=`, `http=`). Never patch our own modules.
5. **Refactoring is not part of the loop.** It belongs to the review stage: a two-axis review (Standards: this file and these rules; Spec: the brief and, for the scraper, `docs/clean-room/scraper-spec.md`) against the diff, after green.

Name tests with the glossary's terms (`GLOSSARY.md`).

## Development

- Tests: `python3 -m unittest discover -s tests` (finalize.py, webpages.py, images.py, video.py, cdp.py, pixels.py; `tests/test_browser_integration.py` drives a local Chromium-family browser when one is installed and skips otherwise; `METADUMP_LIVE=1` adds network tests) and `node --test tests/workflow.test.mjs` (Workflow script control flow with mocked agents). Fixtures live in `tests/fixtures/`.
- Validate: `claude plugin validate .`
- Every Python script in `skills/metadump/scripts/` is Python 3.9+ standard library only; keep it that way so it runs anywhere the skill is installed. Optional tools (a Chromium-family browser, yt-dlp, ffmpeg/ffprobe, sips) are detected at runtime by `tools.py` and never installed. `METADUMP_DISABLE=browser,ffmpeg` hides tools to test the fallbacks.
- `webpages.py` is a clean-room implementation (`docs/clean-room/`, `docs/adr/0004-clean-room-scraper.md`): change it from the spec and our own requirements, never by reading the original project.
- Use the glossary's terms (`GLOSSARY.md`) in code, docs and skill text.
