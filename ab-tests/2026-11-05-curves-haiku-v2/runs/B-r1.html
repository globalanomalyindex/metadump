Sticky and punchy: three curves

One interaction in three moments. Each card loops its curve forward, holds at the target, and returns on the same curve mirrored, so the full path shows.

Press reads as punchy: a fast attack and a hard stop. Release reads as punchy and sticky: one shallow kick past the target that catches and holds. Settle reads as sticky: a slow grip, then a release into a quiet tail. The dashed grey curve in each graph is ease-out, for comparison.
