# TDD seams

The agreed public seams this repo is tested at. Tests live at these seams and nowhere else; a new seam is proposed to the user first (with what it catches and what it misses) and added here once agreed. Rules of the loop are in `CLAUDE.md` ("Testing (TDD)"). Vocabulary is `GLOSSARY.md`'s.

| Seam | Interface under test | Catches | Misses | Tests (0.5.1) |
|---|---|---|---|---|
| S1 finalize | `finalize.py` CLI, `build_dump`, `merge_workdir`, `finish` | provenance ceilings per ticket type (including `scrape`, `watch`, `moodboard`, and found tickets capped at `researched` with their sources relabeled as found online), the task ladder and the user's whole job (`no_task_ladder`, `no_task_job`), tier 1 collected-only and signature trimmed to tier 1, grounding stats (share and hosts) printed by build with `low_grounding` and `narrow_sources`, `narrowing_language` sparing constraints and negations, `image_not_viewed` matched by image id, page, video timecode or url, options groups with `_about` notes (also notes-only), source kinds, `method` warnings, validation, index, routes, layout | semantic quality of a dump | `tests/test_finalize.py` (86) |
| S2 page parse | `webpages.py`: HTML or local file plus URL in, page record out (clean text, metadata, links, images, outline, chunks) | structure kept, boilerplate dropped, metadata fields, link and image resolution, chunk sizes and spans, malformed input never raises, content-type gate | network behavior, real-site quirks | `tests/test_webpages.py` classes CleanText, Metadata, Links, Images, MainContent, Robustness, ContentTypeGate, Chunking, LocalFilesAndOutput (44) |
| S3 fetch policy | `webpages.py` `Fetcher`, `RobotsPolicy`, `Cache`, rate limiter, crawl planner, with an injected raw fetcher and clock | robots rules, per-host delay, cache hit/miss/max-age, size and time limits, allowlist, depth and page limits, URL normalization, skip reasons | live sites (the opt-in `Live` test only) | `tests/test_webpages.py` classes UrlsAndCrawl, Robots, CacheAndRate (12); `Live` (1, `METADUMP_LIVE=1`) |
| S4 video page data | `video.py`: watch-page HTML or player JSON fixture in, media record and caption track list out | title, duration, fps, chapters, track choice, login walls reported not bypassed, same record shape from every engine | live page changes (opt-in live test only) | `tests/test_video.py` class PlayerData (9) |
| S5 captions | `video.py`: VTT, SRT, JSON or XML caption text in, cues and transcript out | cue parsing, tag stripping, rolling auto-caption dedupe, timecode format, speaker paragraphs | caption quality itself | `tests/test_video.py` classes Timecodes, Captions, Transcript (12) |
| S6 PNG decode | `pixels.py`: PNG bytes in, width, height and pixels out (plus encode, gray, downscale) | every color type and bit depth, Adam7, palette and transparency, filters, truncation errors | other image formats (those go through the browser or `sips`, S10) | `tests/test_images.py` classes PngDecode, PngEncodeAndConvert, Formats (18) |
| S7 palette sampling | `images.py`: pixels in, palette out; converter chain with injected converters | top colors with proportions and hex, near-color merging, transparent pixels ignored, fallback order and "palette unavailable" reason | perceptual accuracy | `tests/test_images.py` classes Palette, Conversion (6) |
| S8 timing analysis | `video.py`: grayscale frame sequence plus fps in, timeline out (motion segments, holds, stepped timing, easing) with timecodes and frame numbers | durations in seconds and frames, holds, on-twos, easing class and fit error, noise floor, frame record fields and sampling plans | real capture jitter (S11) | `tests/test_video.py` classes TimingAnalysis, Easing, FrameRecords (11) |
| S9 moodboard | `images.py`: media manifest in, moodboard HTML out | images, captions, source links, palette chips, provenance labels, relative paths, dedupe by hash, found images collected as found online with page, title and license (fetcher injected), page screenshots collected from page records, screenshots and found images linked to their pages on the moodboard, logos, icons and single-color images skipped | how it looks | `tests/test_images.py` classes Manifest, FoundImages, PageScreenshots, PageImageNoise, Moodboard (11) |
| S10 browser seam | `cdp.py`: WebSocket client against an in-process stdlib server, DevTools endpoint parsing, request/response router with a fake transport, browser detection with a fake filesystem; page open, evaluate, screenshot clip against the real local browser | framing, handshake, fragmentation, ping/pong, close, id matching, detection and install hints, screenshot geometry | other browsers' quirks; skips when no Chromium-family browser exists | `tests/test_cdp.py` (32); `tests/test_browser_integration.py::test_screenshot_decodes_with_stdlib_png` (1) |
| S11 end to end | real local browser plus a local animated page served on 127.0.0.1: captured frames into the timing analysis | the known schedule (0.4 s move, 0.5 s hold, 0.4 s move; CSS keyframes 40/30/30) recovered within 70 ms | network video (opt-in live test only); skips without a browser | `tests/test_browser_integration.py` (2) |
| S12 workflow control flow | `index.workflow.js` run with mocked agents | wave order, new ticket types in the evidence wave, discovery (picks become found watch and scrape jobs that run before the moodboard and say they are web-found, caps per depth on videos, pages and images with every drop reported, one discover per wave, fresh ids, found images handed to the moodboard or an added one, discover in gap rounds with its own moodboard pass, found pages screenshotted and interpreted with their URL shell-quoted, a moodboard for anything found), verify narrowings as tier-1 gaps with one widening round at lite, and verify again after a small widening, budgets per depth, gap rounds, contradictions as tier-1 gaps, stop rules | what agents actually write or find | `tests/workflow.test.mjs` (31) |

Engine fallback and degradation tests (`tests/test_video.py` class Engines, 12) sit at the S4/S8 public entry points with the tool detector and the HTTP boundary injected.

Mocks are allowed only at system boundaries: the network (injected fetcher), the browser transport (fake transport or the real local browser), time (injected clock) and, where needed, the filesystem (temp dirs, fake path lookups). Our own modules are never patched.
