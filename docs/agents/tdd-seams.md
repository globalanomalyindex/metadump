# TDD seams

The agreed public seams this repo is tested at. Tests live at these seams and nowhere else; a new seam is proposed to the user first (with what it catches and what it misses) and added here once agreed. Rules of the loop are in `CLAUDE.md` ("Testing (TDD)"). Vocabulary is `GLOSSARY.md`'s.

Mocks are allowed only at system boundaries: the network (injected fetcher), the browser transport (fake transport or the real local browser), time (injected clock) and, where needed, the filesystem (temp dirs, fake path lookups). Our own modules are never patched.
