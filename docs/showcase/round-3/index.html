Same model, same prompt, three ways.

MetaDump’s confirmation test: four tasks picked by the owner after the skill was frozen, with the rules and the pass mark written down before any task was known.

Every build below was made by Sonnet 5.5 at medium effort from the exact prompt shown. Prompt alone got just the prompt. Quick mode first wrote its own small meta dump in one pass, no agents. Full build first got a meta dump made by a swarm of Haiku agents (MetaDump’s lite depth). Blind Sonnet graders scored all twelve builds of each task without knowing which was which.

Quick mode’s win leans on the block world (24–0–0); without it, +0.55 (p = 0.23). The prompt alone won the bento menu. 4 builds per side per task, AI graders.

Because of this test, quick mode is now MetaDump’s default (1.1.0): say “make a metadump for …” and you get quick. lite and heavy run the swarm.

Run 1 of each side is shown by default, on every task; run numbers were fixed before grading. Switch runs to see all four. Scores are the registered blind grades (mean of three graders per build).
